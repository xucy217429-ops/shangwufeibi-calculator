# 商务费比计算器｜手机网页快捷方式版

本包把 23 版计算器整理为可通过手机浏览器访问、添加到主屏幕的网页应用。计算仍在浏览器本地完成，不需要自建服务器、数据库或付费域名。首次打开后会缓存页面，之后可离线使用。

## 零费用发布（GitHub Pages）

GitHub Pages 的免费方案要求仓库为公开仓库，因此仓库里的网页源码任何人都能查看。计算器没有把输入数据发送到托管平台；不过如果不希望源码公开，请使用下面的“本地文件方式”。

1. 注册/登录 GitHub，创建一个 **Public（公开）** 仓库。
2. 将本文件夹内的 `index.html`、`manifest.webmanifest`、`sw.js`、`icon.png` 上传到仓库根目录。
3. 在仓库 **Settings → Pages**，选择从 `main` 分支的根目录发布并保存。
4. 等待 Pages 显示网址后，用手机浏览器打开该网址。首次打开需要联网。
5. Android Chrome：菜单 →“添加到主屏幕”或“安装应用”。iPhone Safari：分享 →“添加到主屏幕”。
6. 打开一次后网页会缓存；以后可以从桌面图标打开，支持离线计算。

无需购买域名。GitHub Pages 对免费账户要求使用公开仓库；官方说明：[GitHub Pages 使用条件](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

## 本地文件方式（完全离线、不公开源码）

把 `index.html` 发到手机并用浏览器打开即可离线计算。此方式无需账号、服务器或费用；不同手机对本地 HTML 的打开和“添加到主屏幕”支持不同，通常不如 Pages 网页快捷。

## 更新

改动文件后重新上传到仓库。若手机还显示旧内容，关闭网页后重新打开，或清除该站点缓存。
