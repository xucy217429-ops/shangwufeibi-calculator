# 商务费比与 ROI 智能测算系统（电商直播与达人营销决策工具）

一款专为品牌方、电商操盘手、媒介投放团队及达人商务打造的高端决策测算系统。深度集成**千川投流**、**达人商务成本（坑位费+佣金）**与**退货率**，统一 GMV（退款前）与 GSV（退款后结算）双口径，提供实时动态联动推导与多维度可视化。

---

## 🚀 本地开发与构建启动指南

### 环境要求
- Node.js >= 18.0.0
- npm / yarn / pnpm / bun

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
启动后在浏览器打开：`http://localhost:3000`

### 3. 生产环境构建打包
```bash
npm run build
```
构建生成的文件位于 `dist/` 目录下。

## 💡 核心测算口径与公式

### 1. 四种反推与正推口径
1. **按目标综合费比反推（GMV口径）**
   - 目标：将综合费比锁定在 GMV 的设定百分比内
   - 核心公式：`GMV = 达人坑位费 ÷ [目标综合费比 − 达人佣金率 × (1 − 退货率) − 1 ÷ 支付 ROI]`
2. **按结算综合费比反推（GSV口径）**
   - 目标：以扣除退款后的实际到手结算额为基准锁定费比
   - 核心公式：`GMV = 达人坑位费 ÷ [(结算综合费比 − 达人佣金率) × (1 − 退货率) − 1 ÷ 支付 ROI]`
3. **按目标 GMV 测算**
   - 输入退款前成交总额，系统按退货率正推 GSV、达人佣金、投流消耗及综合费比
4. **按目标 GSV 测算**
   - 输入扣除退款后预期结算额，反推退款前所需冲击的 GMV 及预算支出

### 2. 三种核心 ROI 说明
- **支付 ROI（广告 ROI）** = `支付 GMV ÷ 千川广告消耗`（衡量纯投流效率）
- **净成交 ROI（结算 ROI）** = `退款后 GSV ÷ 千川广告消耗 = 支付 ROI × (1 − 退货率)`（衡量扣退后的投流转化）
- **全成本 ROI（综合 ROI）** = `支付 GMV ÷ 总营销费用（坑位费 + 佣金 + 千川消耗）`（与综合费比互为倒数）
